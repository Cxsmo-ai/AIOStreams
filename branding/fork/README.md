# Cxsmo fork identity

These are visual identity assets for the Cxsmo community fork README and repository presentation:

- `cxsmo-mark.svg` — the official AIOStreams symbol with a violet `+` fork marker on a dark rounded tile; the square PNG export is used in the README for visibility on both light and dark themes.
- `cxsmo-banner.png` — wide banner used in the README.
- `cxsmo-banner.svg` — previous vector banner draft retained as an editable alternative; it is not the current README artwork.

The README banner uses the official AIOStreams symbol, the AIOStreams name, and a violet `+` fork marker on a dark background. The plus distinguishes this independent community fork; it does not imply endorsement or an official upstream release.
