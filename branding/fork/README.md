# Cxsmo fork identity

These are visual identity assets for the Cxsmo community fork README and repository presentation:

- `cxsmo-mark.svg` — a square AIOStreams+ lockup using the official symbol and wordmark on a dark rounded tile; its PNG export is used in the README for visibility on light and dark themes.
- `cxsmo-banner.png` — wide banner used in the README.
- `cxsmo-banner.svg` — previous vector banner draft retained as an editable alternative; it is not the current README artwork.

The README mark and banner both show the official AIOStreams symbol and AIOStreams name with a violet `+` fork marker on a dark background. The plus distinguishes this independent community fork; it does not imply endorsement or an official upstream release.
