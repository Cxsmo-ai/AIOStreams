# Cxsmo fork identity

These are visual identity assets for the Cxsmo community fork README and repository presentation:

- `cxsmo-mark.svg` — the official AIOStreams symbol with a violet `+` fork marker; the square transparent PNG export is used in the README.
- `cxsmo-banner.png` — wide banner used in the README.
- `cxsmo-banner.svg` — previous vector banner draft retained as an editable alternative; it is not the current README artwork.

The README pairs the official AIOStreams symbol plus a violet `+` fork marker with the new blue-and-violet stream banner. The plus distinguishes this independent community fork; it does not imply endorsement or an official upstream release.
