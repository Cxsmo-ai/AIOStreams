# Cxsmo fork identity

These are original visual assets for the Cxsmo community fork README and repository presentation:

- `cxsmo-mark.svg` — editable vector mark; the compact PNG export is used in the README.
- `cxsmo-banner.svg` — editable vector banner; the PNG export is used in the README.

The mark uses the same minimalist, flat geometric discipline as the AIOStreams visual system, with an original three-source junction and purple/cyan fork accents. It does not copy the upstream mark. The application and documentation retain upstream AIOStreams identity where they describe upstream functionality; these assets identify the fork itself.
